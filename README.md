GRUPO 6
ALQUILER DE CANCHA

Nombre del proyecto: Alquiler de Canchas

Problema que resuelve:
Buscamos que el sistema resuelva la problemática la de la mala gestión de horarios al momento de alquilar una de las canchas deportivas, ya sea por cruce de horarios o una mala fecha de reservación.
Tecnologías: React, Spring Boot, PostgreSQL, Neon, Railway, Vercel.

FRONTED Y BACKEND DESPLEGADOS:
BACKEND: https://invigorating-endurance-production-b7e9.up.railway.app
FRONTED: https://alquiler-cancha.vercel.app

FUNCIONES IMPLEMETADAS:
•	Interfaz de crear nuevas canchas
•	Crear el registro de un nuevo cliente
•	Reservación de las canchas a utilizar


PASOS PARA EJECUTAR EL BACKEND Y FRONTED LOCALMENTE:

BACKEND: Utilizar las rutas que están designadas parar cada acción, y saber en qué puerto lo queremos ejecutar, por ejemplo: “localhost:8080” y luego la ruta: “localhost:8080/api/clientes” y lo copiamos en el navegador de prefencia.
FRONTED: Utilizamos la terminal, en donde descargamos las dependencias y librerías que se necesitan para que el proyecto funcione y muestre localmente con el comando “npm install”; Para luego colocar el siguiente comando: “npm run dev” que nos mostrará el proyecto localmente.
